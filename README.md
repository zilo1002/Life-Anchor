# 活下去的意义 - Life Anchor

> 一个安静的数字港湾，在需要的时候，<br>
> 给你一句值得停留片刻的话。

---

## 1. 功能亮点

- ✨ **生命锚点**：点击核心按钮，<br>随机获得一条温暖的内容。
- 🧭 **内容导航**：消息卡片下方提供独立的「上一条 / 下一条」按钮，<br>左侧为上一条，右侧为下一条，同时支持移动端触摸切换。
- 🌏 **双语卡片**：支持「中文 / English / 中英」三种显示模式，<br>中英模式下中文位于上方、英文位于下方。
- 🌐 **系统语言跟随**：网站 UI 自动根据浏览器 / 系统首选语言<br>显示中文或英文。
- 🌓 **主题切换**：支持米色 Light Mode 与深棕 Dark Mode，<br>并保存用户的主题偏好。
- 🔊 **声音交互**：支持水滴声、轻柔点击、机械键盘音效、<br>风铃等声音选项。
- ✨ **氛围动画**：包含呼吸动画、涟漪、光晕与漂浮粒子等<br>轻量视觉效果。
- 💾 **本地偏好**：主题与卡片语言选择保存在浏览器<br>`localStorage` 中。
- 📚 **内容库**：独立维护内容数据，<br>目前包含原有内容与新增 5000 条原创扩展内容。

---

## 3. 隐私与安全

- 所有核心功能均在浏览器本地运行，不需要后端服务。
- 主题偏好与卡片语言选择仅保存在浏览器本地 `localStorage`。
- 内容库直接随网站静态文件提供，不需要上传用户数据。
- 项目核心功能不要求用户注册或登录。
- 不需要上传用户文件。
- 声音、主题、内容浏览等核心交互不依赖第三方服务器。
- 项目中的网络资源应以实际部署版本为准；<br>如使用外部资源，则不应将其描述为完全离线运行。

## 4. 快捷键

| 快捷键 | 功能 |
|--------|------|

> 快捷键支持以实际部署版本为准。
